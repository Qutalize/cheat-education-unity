# レッスン01 ウォールハック（TPS_example 専用手順）

対象: `Multiplayer Third Person Gameplay` 1.0.8 ／ Unity 6000.3.7f1 ／ URP 17.3 ／ NGO 2.7。

---

## 0. オンライン対戦は不要（ここ重要）

このテンプレートには 2 つの Shooter シーンがある:

| シーン | 中身 | このレッスンで |
|---|---|---|
| **`Assets/Shooter/TestScenes/[BB] Shooter.unity`** | `NetworkManager` が **127.0.0.1 のローカル構成**（`UnityTransport` Address=127.0.0.1 / ConnectionApproval=off / 画面に「Start Host」ボタン）。Unity Gaming Services は不要 | ★これを使う |
| `[BB] Shooter MultiplayerSession.unity` | Multiplayer Services（Sessions / Relay / マッチメイキング）＝**オンライン対戦用** | 使わない |

→ **`[BB] Shooter.unity`（無印）を開けば、オンライン接続もサインインも一切不要**。
「Start Host」を押すと自分 1 人のローカルサーバーが立つ。そこに**ボット（練習相手）**を出して
ESP／ウォールハックを試す。

---

## 1. この教材が見せるもの

- **ESP**: 敵（＝ボット or 他プレイヤー）の位置に枠＋名前＋距離＋体力バー。壁の裏でも見える。
- **ウォールハック**: 敵の体を、壁を無視した赤いシルエットで重ね描き。

いずれも照準も弾もいじらない **情報だけのチート**。

---

## 2. なぜ成立するのか（このテンプレートの実コード）

| 仕組み | 実ファイル | 何が起きているか |
|---|---|---|
| 敵の複製 | NGO の既定 | 全プレイヤー／ボットの `NetworkObject` が全クライアントにスポーンされる |
| 位置の同期 | `[BB] ShooterPlayer` / `CheatBot` の `NetworkTransform` | 位置が毎tick同期。壁の有無は見ていない |
| 体力の同期 | `CoreStatsHandler.cs`（プレイヤー）／ `CheatBot.Health`（ボット） | どちらも **Read = Everyone** ＝全クライアントが敵の体力を読める |
| 名前の同期 | `CorePlayerState.cs` | `NetworkVariable` Read = Everyone |

→ あなたのクライアントのメモリに、壁の裏の敵も含めて **座標・体力・名前が毎フレーム存在する**。
`NetPlayerRegistry.cs` はそれを `NetworkManager.Singleton.SpawnManager.SpawnedObjects` から拾うだけ。

---

## 3. セットアップ（自動）

1. Unity の初回インポートが完了し、Console にエラーが無いことを確認
   （エラーがあれば全文を報告してください）。
2. **`Assets/Shooter/TestScenes/[BB] Shooter.unity` を開く**。
3. メニュー **`Tools > Cheat Education > レッスン01 をセットアップ`** を実行。
   これで自動的に:
   - `Assets/CheatEducation/Resources/CheatBot.prefab`（練習相手）を生成
   - それを `DefaultNetworkPrefabs` に登録
   - シーンに `CheatConsole` と `CheatBotSpawner` を追加
4. **シーンを保存**（Ctrl+S）。
5. カメラの Tag が `MainCamera` か確認（`Main Camera` オブジェクト。既定でそうなっているはず）。

> `CheatConsole` は F1 パネル。`NetPlayerRegistry` `WallhackCheat` `EspOverlayCheat` を自動で付ける。

## 4. 操作

| 操作 | キーボード / マウス | PS5 コントローラー |
|---|---|---|
| 移動 | W / A / S / D | 左スティック |
| 視点 | マウス | 右スティック |
| 走る | 左 Shift（押しっぱなし） | 左スティック押し込み（L3） |

> パネル（左上）は**状態表示だけ**。クリック不要。

>
> キーボード操作は Game ビューを一度クリックしてフォーカスを当ててから。コントローラーは
> フォーカス不問。パネルに「コントローラー○ DualSense…」と出れば認識されている。

## 5. 実行（自分 1 人＋ボット）

1. **Play** を押す。
2. 画面の **「Start Host」** をクリック（オンライン接続は不要。ローカルにサーバーが立つ）。
3. 自分のキャラが出て、少し待つと **赤いカプセルのボットが数体うろつき始める**
   （Console に「ボットを N 体生成しました」）。
4. **F2**（または L1）で **ESP を ON**。
   - ボットに枠・`Bot 3` などの名前・距離・体力バーが付く。
5. **F3**（または R1）で **ウォールハックを ON**。
   - パネル（左上）の `01 ウォールハック` が `[ON ]` になり、下の行に
     マテリアル名と「シルエット N/M 体」が出れば動いている。
   - 「敵が 0」「Camera 無し」等が出たら §7 のトラブルシュート。
6. ボットが壁や箱の裏に回り込んでも、**枠と赤いシルエットが見え続ける**。

### ボットが変な位置に出るとき
`CheatBotSpawner` オブジェクトを Hierarchy で選び、**床の上あたり**へ動かす
（Inspector の `Spawn Area Radius` も調整可）。

## 6.（別法）Multiplayer Play Mode で 2 人プレイ

ボットではなく本物の 2 人目で試したいとき:

1. `Window > Multiplayer > Multiplayer Play Mode` → **Player 2** を有効化。
2. Play → メイン画面で「Start Host」、**Player 2 のウィンドウ**でクライアント接続ボタン。
3. Player 2 のキャラが 2 人目の敵になる（動かさなければ的、動かせば練習相手）。

どちらもローカル完結（127.0.0.1）。UGS サインインを求められたら不要なのでキャンセル。

## 7c. PS5 コントローラー：旧 Input ブリッジ（joy.cpl では動くのに Unity で無反応の場合）

一部の Windows / DualSense の組み合わせで、**新 Input System がデバイスを認識するのに
入力レポートを受け取らない**ことがある（F4 診断で `last=` の数字が固定・スティック値が 0）。
`joy.cpl`（DirectInput）で動くならこの状態。教材が回避策を入れてある:

- `ProjectSettings` の **Active Input Handling を `Both`** に変更済み → **★Unity エディターの再起動が必要**
- `InputManager.asset` に `CE_Axis0..9` を追加済み
- `GamepadBridge`（`CheatConsole` が自動追加）が旧 Input で DualSense を読み、
  新 Input System の仮想パッドへ流し込む → テンプレートの `<Gamepad>/*` バインドがそのまま動く

**手順**:
1. エディターを再起動（Active Input Handling 変更の反映）。
2. Play → Start Host。パネルに `ブリッジ: 仮想パッド作成済み` と出る。
3. スティックで動けるか確認。
4. 動くが**向きが変・スティックが入れ替わっている**場合 → **F8** で校正表示を開く。
   スティックを倒して「いちばん大きい軸 Ax◯」を確認し、Hierarchy の `CheatConsole` →
   `GamepadBridge` コンポーネントの Inspector で `Lx Axis` `Ly Axis` `Rx Axis` `Ry Axis` の
   番号を直す（`Invert LY/RY` も）。
5. それでも全く無反応 → パネルに `Both になっていません` と出ていれば再起動が未反映。

## 7b. PS5 コントローラーが効かないとき（基本チェック）

パネルに `コントローラー○ DualSense` と出ているのに操作できない場合、
**F4（または Options ボタン）で「入力診断」を開く**。

- **スティックを倒すと数値が動く** → 入力は Unity に届いている。ゲーム側の問題
  （Host が動いていない／自分のプレイヤーが居ない／別の設定）。診断の下段
  「Host稼働 / 自分のプレイヤー」を確認。
- **数値が (0.00, 0.00) のまま動かない** → 入力が届いていない。ほぼ環境要因:

| 対処（上から順に試す） | 理由 |
|---|---|
| **USB ケーブルで有線接続**（Bluetooth をやめる） | DualSense の BT は取りこぼしが多い。有線が最も確実 |
| **Steam を完全終了**（タスクトレイからも終了） | Steam Input が DualSense を横取りして Unity に渡さない。最頻出の原因 |
| DS4Windows / DualSenseX など他のパッド管理ソフトを終了 | 同上（排他アクセス） |
| コントローラーの PS ボタンを一度押す／挿し直す | スリープ復帰 |
| `Edit > Project Settings > Input System Package` の **Play Mode Input Behavior** を `All Device Input Always Goes To Game View` に | フォーカス依存の除外 |
| Game ビューを一度クリックしてから操作 | フォーカス |

> Steam を使っている場合の恒久対策: Steam →「設定」→「コントローラ」→
> 「PlayStation コントローラのサポート」をオフ、または Unity/このプロジェクトを
> Steam に登録して個別に Steam Input を無効化。

## 7. トラブルシュート（F1 パネルの状態行を見る）

| 状態行 / 症状 | 原因と対処 |
|---|---|
| 「敵が 0（Start Host 済み？…）」 | Host が始まっていない or ボットが出ていない。Console で `[CheatBotSpawner] ボットを N 体生成` を確認。0 なら CheatBotSpawner を床の上へ。 |
| 「Camera 無し」 | シーンの `Main Camera` の Tag が `MainCamera` か確認。 |
| 「エラー: X-Ray マテリアル未生成」 | シェーダーがコンパイルできていない。Console のシェーダーエラーを貼ってください。 |
| `duplicate GlobalObjectIdHash` | 直近の修正で解消済み。Play を止めて再コンパイル → Play しなおす。 |
| ESP は出るがシルエットが出ない | 状態行のマテリアル名を確認。`URP/Unlit(予備…)` なら壁越しに出るはず。出ないなら報告を。 |

## 9. 次（対策）

`cheat-education-unity/Countermeasures/ServerVisibilityFilter.cs` を
`CheatBot.prefab` と `[BB] ShooterPlayer.prefab` に付け、`wallMask` に壁レイヤーを設定すると、

## 付録: 操作感とボットの調整（2026-09-07 追加）

### 視点感度（① 対応）
`LookSensitivityTweak`（CheatConsole が自動付与）がローカルプレイヤーの
`CoreCameraController.SetLookSensitivity` を毎フレーム上書きして感度を上げている。
既定 2.5。速すぎ/遅すぎる場合は Hierarchy の `CheatConsole` → `LookSensitivityTweak` →
`sensitivity` を変更（マウスと共通の感度）。

### ボット（②〜⑤ 対応）
`CheatBot`（サーバー権威 AI）を作り直した:
- **攻撃する**: プレイヤーが `detectRange` 内かつ射線が通ると接近し、`fireInterval` ごとに
  プレイヤーの `IHittable.OnHit` を呼んで**ゲーム本来のダメージ処理**で体力を削る。
- **撃たれると減る/倒せる**: `CheatBot` が `IHittable` を実装。プレイヤーの弾が当たると
  `Health` が減り、0 で 3 秒後にリスポーン（繰り返し撃破を試せる）。
- **陣地から出ない**: `CheatBotSpawner` が各ボットに中心と半径を渡し、その円内へ毎フレーム制限。
- **固まらない**: 各ボットが自分の巡回中心の周りをランダム徘徊＋接地。

調整は Hierarchy の各 `CheatBot`（または `CheatBotSpawner` の spawnAreaRadius / botCount）で可能。
`detectRange` `attackRange` `fireInterval` `damagePerShot` `moveSpeed` `wanderRadius` を Inspector で調整。

> ★これらのボットの被弾・加害はどちらも `Blocks.Gameplay.Core.IHittable` → `CoreStatsHandler.ModifyStat`
> という**ゲーム本来のダメージ経路**を通る（張りぼてではない）。だからレッスン05 の対策
> （サーバーがダメージを検証/権威化）を入れると、この経路がそのまま検証対象になる。
